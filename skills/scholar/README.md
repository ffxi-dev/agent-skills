# scholar

Ask Scholar, Vault's index of every archived retail FFXI capture, questions in SQL: which mobs and NPCs appear in a zone, where and how often, their HP, claims, and positions; what the recording character wore; zones visited; any packet's decoded fields across every capture. Use it whenever a question about what retail does could be answered from captured packets, before grepping logs one capture at a time. Every row links to its packet in Lens, so an answer can be checked against the bytes. Needs SCHOLAR_API_KEY, a key made at https://scholar.sruon.dev/keys.

See [SKILL.md](SKILL.md) for the full instructions, and the [repo README](../../README.md) for how skills are installed.

**Requirements:** Requires Python 3.9+, network access to scholar.sruon.dev, and SCHOLAR_API_KEY.
