# ffxi-resources

Look up trusted FFXI reference values decoded straight from the retail client DATs. Use to find a message or string ID and its text, an item ID and its properties, event bytecode and the decompiled Lua for an NPC event, ability, spell, status effect, key item, merit, augment or monster-family data, an NPC or monster entity name by id, or a zone id and name. Use it whenever you need to VERIFY a "trusted" FFXI value rather than recall one: this is a direct decode of the game's own resource files, not a wiki claim, so the numbers are authoritative. Prefer it over ffxi-wiki when the question is about an exact id, string, or bytecode value.

See [SKILL.md](SKILL.md) for the full instructions, and the [repo README](../../README.md) for how skills are installed.
