# ffxi-version-updates

Search official FFXI version update and patch notes in both English and Japanese, 2002 to present. Use whenever a question is about WHEN or HOW something changed in retail FFXI: "when was X added", "when did Y get nerfed or buffed", "what changed in the March 2014 update", "was this mechanic in the game at era Z", "when did the cap on X get raised", "when was zone/job/item/system N introduced". Also use to date a mechanic for era accurate private server work (LSB, HorizonXI, 75 cap projects), and whenever the English patch note is vague, ambiguous, or reads like a bad translation, since the Japanese original is the source text and is kept alongside.
