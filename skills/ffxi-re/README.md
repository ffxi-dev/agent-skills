# ffxi-re

Reverse-engineer Final Fantasy XI client internals - the decompiled PS2 client (FFXI-PS2), the retail FFXiMain.dll, and the PS2 SCUS_972.66 ELF. Use when asked to find how the client implements something (animation/lock timers, event & cutscene flags, chat limits, movement/collision, packet handling, UI), to locate a byte signature to patch, to confirm a flag or field's meaning, or to compare PS2-era behavior against retail. Triggers on FFXI/FFXi/XI + client, decomp, FFXiMain.dll, SCUS_972.66, packet, opcode, signature, cutscene flag, or reconciling private-server (LSB) behavior with client code.
